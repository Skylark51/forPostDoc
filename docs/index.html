사용 방법

기준은 개별 파일이 아니라 연구 프로젝트입니다.

웹에서 SI를 만들 때

별도 설치 없이 브라우저에서 바로 사용할 수 있습니다.

  • 1. 프로젝트와 모듈을 선택합니다.
  • 2. 에너지·스핀·구조 표에 값을 입력하거나 표 계산 프로그램에서 붙여넣습니다.
  • 3. 상대 에너지 계산값을 다시 계산합니다.
  • 4. DOCX 또는 JSON으로 저장합니다.

데스크톱 프로그램에서 계산을 정리할 때

Gaussian 계산 결과와 분석 기능을 프로젝트 단위로 연결합니다.

  • 1. 프로젝트를 선택합니다.
  • 2. Gaussian 출력 파일을 가져옵니다.
  • 3. 에너지·스핀·구조·진동수 자료를 확인합니다.
  • 4. 반응좌표 그림과 SI 자료로 연결합니다.
