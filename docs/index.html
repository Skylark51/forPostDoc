Computational Chemistry Report Assistant

DFT 계산 데이터와 연구 Figure를 프로젝트별로 관리하여 주간 연구보고서와 Supporting Information 작성에 활용하기 위한 도구입니다.

현재 단계: 프로젝트 관리 + Reaction Coordinate Editor

프로그램의 기본 구조

모든 기능은 프로젝트 아래에 위치합니다. 계산 파일, Google Drive, Google Sheet, 추출 데이터, Reaction Coordinate Figure를 프로젝트/모듈 단위로 관리합니다.

Reaction Coordinate Editor

ChemDraw처럼 캔버스에서 직접 조작하는 방식으로 반응 좌표와 메커니즘 Figure를 작성합니다. 복잡한 입력창보다 클릭·드래그·정렬을 우선합니다.

  • 빈 공간 더블클릭 또는 노드/TS 도구로 species 추가
  • 연결 도구에서 source → target를 차례로 클릭하여 화살표 생성
  • 노드 드래그, 다중 선택, 복제, 삭제, Undo/Redo
  • chain / circular / branched / freeform 자동 배치
  • 왼쪽·가운데·오른쪽 / 위·가운데·아래 정렬과 균등분배
  • 에너지, local barrier, spin/multiplicity, subtitle 표시 제어
  • 프로젝트의 Gaussian output을 노드에 연결하여 raw electronic energy provenance 보존
  • PNG, SVG, JSON, clipboard image 출력

자동 배치 후에도 모든 위치를 수동으로 다시 움직일 수 있으며, 원본 Gaussian output은 수정하지 않습니다.

Gaussian output에서 관리하는 데이터

  • 파일명 / 프로젝트 / Normal termination
  • Charge / multiplicity / method / basis set
  • 최종 electronic energy와 상대에너지 계산용 raw value
  • 최종 optimized geometry와 XYZ
  • Reaction Coordinate node와 연결된 Gaussian provenance

Google Drive / Google Sheets

각 프로젝트의 실제 Drive 폴더와 Google Sheet를 개별적으로 연결합니다. OAuth 인증정보와 실제 연구 데이터는 공개 저장소에 저장하지 않습니다.

현재 구현된 기반

  • 프로젝트별 독립 설정과 Google Drive/Sheets 연동 구조
  • Gaussian .out/.log 다중 불러오기 및 drag & drop
  • SQLite raw-data 저장과 SHA-256 중복 확인
  • 최종 SCF energy / XYZ 추출
  • 프로젝트별 Reaction Coordinate Editor
  • Reaction Coordinate JSON 로컬 저장 및 PNG/SVG 출력
