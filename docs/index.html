OUT로컬 프로그램

Gaussian 결과 정리

.out·.log 파일에서 정상 종료, 전하, 스핀 다중도, 계산 방법, 최종 에너지와 구조를 추출합니다.

E로컬 프로그램

반응 경로별 에너지와 Mulliken 스핀 밀도, 주요 결합거리 및 선택 구조를 프로젝트 단위로 정리합니다.

TD로컬 프로그램

TD-DFT · 진동수

전자전이와 진동수 계산 결과를 프로젝트 기록과 함께 관리하고 보고서 작성 흐름에 연결합니다.

GD연동 기능

웹에서 바로 할 일

SI 생성기는 별도 설치 없이 브라우저에서 바로 실행할 수 있습니다. 프로젝트와 모듈을 선택한 뒤 표를 작성하고 DOCX로 출력합니다.

  • 1. 프로젝트와 모듈 선택
  • 2. 에너지·스핀·구조 표 입력
  • 3. 상대에너지 자동 계산
  • 4. DOCX 또는 JSON으로 저장

로컬 프로그램에서 할 일

Windows 프로그램에서는 Gaussian 파일 가져오기, 반응좌표 편집, Drive/Sheets 연동 등 전체 연구 데이터 흐름을 다룹니다.

  • 계산 결과: Gaussian 출력 파일 파싱 및 구조 추출
  • 메커니즘: 에너지·스핀·구조 비교와 반응좌표 구성
  • 자료 관리: 프로젝트별 Drive와 Sheet 연결
  • 보고서: SI 생성기와 후속 보고서 모듈로 연결
