Computational Chemistry Report Assistant

DFT 계산 데이터를 프로젝트별로 정리하고, 주간 연구보고서와 Supporting Information 작성에 활용하기 위한 연구 관리 도구입니다.

현재 단계: 프로젝트·데이터 관리 기반 구축

프로그램의 기본 구조

기능보다 프로젝트 관리 구조를 우선합니다. 모든 계산 파일, Google Drive 폴더, Google Sheet, 추출 데이터는 반드시 하나의 프로젝트에 소속됩니다.

Project → Module → Gaussian file → Raw data → 분석 결과 → Report / SI

현재 관리 중인 프로젝트

프로젝트 주요 관리 단위 연동 대상
1. Deformylation_UNIST Normal / Protonated mechanism, Hydroperoxo 관련 계산 프로젝트 Drive + Google Sheet
2. FeNO6_UNIST FeNO6/7, HNO2 binding, protonation, N–O cleavage, TD-DFT 프로젝트 Drive + Google Sheet
4. CoNO7_UNIST CoNO7 및 Co–nitrite 계산 프로젝트 Drive + Google Sheet
5. Co_sidearm Main mechanism, Rebound, Radical coupling, TD-DFT 프로젝트 Drive + Google Sheet
6. Mn(IV)-dichloride Spin state, 구조 비교, TD-DFT 프로젝트 Drive + Google Sheet

Gaussian output 파일을 불러오면 관리할 데이터

  • 원본 파일명과 프로젝트 소속
  • Normal termination 여부
  • Charge / multiplicity / method / basis set
  • 최종 electronic energy와 이후 상대에너지 계산에 사용할 raw value
  • 최종 optimized geometry와 자동 추출된 XYZ
  • 향후 Mulliken spin density, frequency, TD-DFT, geometry parameter 등 분석 데이터

원본 Gaussian 파일은 수정하지 않고, 데이터베이스에는 추출값과 파일 식별 정보만 저장하는 것을 기본 원칙으로 합니다.

Google Drive / Google Sheets 연동 방향

각 프로젝트는 현재 사용 중인 Drive 폴더와 Google Sheet를 개별적으로 연결합니다. 프로그램에서는 프로젝트를 선택한 뒤 해당 Drive와 Sheet를 바로 확인하고, 계산 결과와 기존 정리표를 같은 프로젝트 단위에서 다룰 수 있도록 구성합니다.

OAuth 인증정보와 실제 연구 데이터는 공개 저장소에 저장하지 않습니다.

현재 구현된 기반

  • 프로젝트별 독립 설정 파일
  • PySide6 기반 프로젝트 중심 GUI 골격
  • .out / .log 다중 불러오기 및 drag & drop
  • SQLite 기반 프로젝트별 raw-data 저장
  • SHA-256 기반 중복 파일 확인
  • 최종 SCF energy 및 XYZ 추출
  • Google Drive / Sheets OAuth 연동 모듈
