Computational Chemistry Report Assistant

Architecture first

CCRA organizes research as Project → Module → File/Data. Analysis is subordinate to the project record.

Raw data

Imported Gaussian outputs are hashed and indexed with final energy, charge, multiplicity and extracted XYZ.

Privacy boundary

The public repository contains integration metadata and code, not spreadsheet cell contents, OAuth secrets, or Gaussian output files.
