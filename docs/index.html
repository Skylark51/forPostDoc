Computational Chemistry Report Assistant

DFT 계산 데이터, 반응 좌표 Figure, Supporting Information을 프로젝트 단위로 관리하는 연구 도구입니다.

Project → Module → File/Data → Figure / SI

핵심 기능

SI Generator

Absolute/Relative Energy, Mulliken Spin Density, Selected Geometry를 빠르게 편집하고 SI 형식의 DOCX로 생성합니다. 브라우저 로컬 저장과 프로젝트별 Google Drive 저장/불러오기를 지원합니다.

SI Generator 열기 →

Reaction Coordinate Editor

Chain / Circular / Branched / Freeform 반응 경로를 직접 편집하고 Gaussian provenance와 함께 PNG/SVG/JSON으로 관리합니다.

기능 및 소스 보기 →

프로그램의 기본 구조

SI Generator

  • 업로드된 SI 형식의 4개 핵심 표 구조를 기반으로 한 편집기
  • Absolute Energy / Relative Energy / Mulliken Spin Density / Selected Geometry
  • Structure 행 추가·삭제, Spin/Geometry 열 자유 추가, Excel/Google Sheets TSV 붙여넣기
  • ΔE Total 및 ΔG template 식 자동 재계산
  • 브라우저 localStorage + JSON import/export + 실제 DOCX 생성
  • 프로젝트별 Google Drive 폴더에 SI JSON 저장/불러오기
  • 외부 UI framework 없이 동작하며 Google OAuth 스크립트는 Drive 연결 시에만 로드

로컬 프로그램

Windows/Python GUI에서도 프로젝트를 선택한 뒤 SI Generator 탭을 사용할 수 있습니다. 로컬 JSON/DOCX와 프로젝트 Drive 동기화를 같은 데이터 모델로 관리합니다.
