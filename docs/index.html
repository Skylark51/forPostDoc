계산화학 연구 보고서 도우미

Gaussian 계산 결과와 프로젝트 자료를 한곳에서 정리하고, 반응좌표 그림과 Supporting Information(SI) 문서를 만드는 연구 보조 도구입니다.

프로젝트 → 모듈 → 계산 파일/데이터 → 분석 → 반응좌표/SI → 보고서

웹에서 바로 사용할 수 있는 기능

웹 실행 가능

SI Generator

절대 에너지, 상대 에너지, Mulliken 스핀 밀도, 선택 기하구조 표를 편집하고 실제 DOCX 형식의 SI 문서를 생성합니다. 프로젝트별 로컬 저장, JSON 가져오기·내보내기, Google Drive 저장·불러오기도 지원합니다.

웹 프로젝트 목록

프로젝트 연결

Deformylation, FeNO6, CoNO7, Co sidearm, Mn(IV)-dichloride 프로젝트와 각 모듈 정보를 불러와 SI 문서를 프로젝트 단위로 관리합니다.

Windows 데스크톱 프로그램 기능

아래 기능은 현재 PySide6 기반 로컬 프로그램에서 프로젝트를 선택한 뒤 사용할 수 있습니다.

로컬 기능

반응좌표 편집기

중간체와 전이상태를 직접 배치하고 연결선을 편집합니다. 선형·원형·분기·자유 배치와 PNG/SVG/JSON 내보내기를 지원합니다.

소스 보기 →
로컬 기능

Gaussian 파일 가져오기

.out·.log 파일을 여러 개 가져와 정상 종료 여부, 전하, multiplicity, method/basis, 최종 전자에너지와 구조를 정리합니다.

로컬 기능

에너지 분석

프로젝트에 저장된 계산 결과를 바탕으로 에너지 자료를 모아 반응 메커니즘 비교와 보고서 작성에 연결합니다.

로컬 기능

스핀 밀도

Mulliken spin density 자료를 프로젝트별로 정리하고 SI 표 또는 메커니즘 해석 자료로 사용할 수 있도록 구성합니다.

로컬 기능

구조 자료

Gaussian 최종 구조에서 주요 결합거리와 선택 기하구조를 정리하고 SI 작성 흐름과 연결합니다.

로컬 기능

TD-DFT · 진동수

TD-DFT 및 frequency 계산 결과를 프로젝트의 계산 기록과 함께 정리하기 위한 전용 탭을 제공합니다.

로컬 기능

Google Drive · Sheets

각 프로젝트에 지정된 Drive 폴더와 Google Sheet를 열고, 계산 자료와 보고서 자료를 프로젝트 단위로 연결합니다.

로컬 기능

SI 생성기

웹 버전과 같은 데이터 구조를 사용하며, 로컬 JSON/DOCX 저장과 프로젝트 Drive 동기화를 지원합니다.

로컬 기능

후속 작업 정리

프로젝트별 계산 진행 상황과 다음 계산 항목을 한 화면에서 정리할 수 있는 확장용 작업 영역입니다.

프로그램의 기본 구조

모든 기능은 프로젝트 아래에 위치합니다. 계산 파일, Google Drive, Google Sheet, 추출 데이터, 반응좌표, SI 문서를 프로젝트와 모듈 단위로 관리합니다.

프로젝트 → 모듈 → Gaussian 파일/원자료 → 분석 → 반응좌표/SI → 보고서
