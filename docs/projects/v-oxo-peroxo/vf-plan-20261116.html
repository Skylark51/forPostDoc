입력과 실행 순서

실행본은 덤보의 실제 input.sh를 호출해 생성했습니다. 기존 연구 조건 UB3LYP-D3BJ/def2SVP, CPCM(MeCN), +1/doublet을 유지합니다. 이전 준비본에 임의로 추가됐던 tight·ultrafine·maxcycles·SCF 128 옵션은 초기 입력에서 제거했습니다. Scan은 기존 template-scan-nooldchk.txt의 route와 승인된 탐색 좌표를 사용합니다.

  • Minimum 두 건: opt → freq → 허수 0개 확인 → bb. 실패 시 다음 단계로 진행하지 않습니다.
  • TS 계열: 복구된 freq checkpoint → TS → freq → 유효한 허수 모드 1개 확인 → bb → IRC forward/reverse → 양 끝점 opt → freq → 허수 0개 확인 → bb.
  • TS 에너지 15 kcal/mol 이상 하락 시, 설치된 wf에 정의된 원래 oldchk 유지·calcfc 재시도를 한 번만 적용합니다. Minimum 허수 잔존 시에도 wf 방식의 checkpoint 재최적화를 한 번 거쳐 다시 검증합니다.
  • 2차원 map은 전체 격자를 먼저 계산합니다. 현재 wf의 1차원 peak 자동 중단 기능을 그대로 적용하지 않으며, 결과 검토 후 선택한 후보에서 wf 순서로 후속 계산합니다.

기존 wf worker와 wf-core의 정상 종료·수렴·진동 모드·IRC 판정을 사용합니다. 전역 input.sh/wf 코드는 수정하지 않았습니다.
