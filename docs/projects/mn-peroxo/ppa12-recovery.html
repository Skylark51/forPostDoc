연결 검증 진행 중

목표는 비배위 최소점 ↔ 배위 최소점, 배위 최소점 ↔ PHA adduct의 두 연결입니다. 기존 Coord/PHA 회전 TS는 형성 단계의 증거로 사용하지 않습니다. CC 절단 구간은 이전 검증 결과를 유지합니다.

작업 / 노드상태 / 단계출력 관찰IRC endpoint

실행한 복구·탐색

  • lion21 / forCoord-2-scan: 원래 Coord 접근 scan의 마지막 수렴점(Mn–O 약 3.916 Å)부터 복구. 수렴점의 내부 최대 후보가 확보되면 freq → TS → freq로 이어집니다. 배위 구간에 최대점이 없으면 검토 필요로 남깁니다.
  • lion43 / forCoord-3-qst2: 비배위·배위 최소점을 사용한 별도 QST2 탐색.
  • lion42 / AfterCoord-forPHA-2-freq: 실제 O2–C12 결합 형성 구간의 scan 구조에서 freq → TS(RCFC,NoFreeze) → freq. 첫 후보가 검증을 통과하지 못하면 bound/adduct QST2 후보를 순차 탐색합니다.

원본 인풋 형식

파일명은 forCoord / AfterCoord-forPHA와 단계 suffix를 사용합니다. %CPU=0-15, %mem=60Gb, B3LYP-D3(BJ)/def2-SVP, CPCM(MeCN), +1 / multiplicity 5를 유지합니다. 제목은 opt / freq / TS opt / IRC forward / IRC reverse로 맞췄습니다.

처음 작성한 다른 형식의 세 작업은 별도 보존 후 종료했고, 위 형식으로 07:04 KST경 다시 시작했습니다. 추가했던 UltraFine와 SCF maxcycle=512는 제거했습니다. 원래 중단 지점이 FMM 활성 l703이었으므로 int=fmmnatoms=1000만 장애 우회 설정으로 별도 적용했습니다. 이 설정으로 장애 원인이 확정되었다는 뜻은 아닙니다.

연결 완료 판정

  1. TS 주파수 189개 중 허수 1개, 그 모드에 목표 Mn–O 또는 O–C 결합 변화가 포함되어야 합니다.
  2. TS의 파동함수 안정성 검사를 통과해야 합니다.
  3. 양방향 IRC가 정상 완료된 후 각 endpoint를 opt·freq로 확인합니다.
  4. 양쪽 최소점 허수 0개, 각 목표 기준 구조와 중원자 RMSD 0.15 Å 이내(페닐 대칭 대응 허용)인지 대조합니다.

조건을 통과한 구간만 연결 확인으로 표시합니다. 다른 conformer, 전자상태 불안정, 미완료 또는 후보 소진은 검토 필요로 남깁니다. Scan 에너지 최대점과 최종 TS를 구분합니다.

서버의 후속 계산은 노드에서 이어집니다. 홈페이지는 게시된 확인 시각 기준의 기록입니다. 확인 도구가 실행 중이면 단계 변경 시와 약 15분 간격으로 기록을 게시합니다. 브라우저의 새로 읽기는 최신 게시 자료를 가져옵니다.
