# PostDoc 연구 대시보드

[프로젝트 선택](https://skylark51.github.io/forPostDoc/)

- [Mn(III)–peroxo](https://skylark51.github.io/forPostDoc/projects/mn-peroxo/)
- [Co–Si α · γ](https://skylark51.github.io/forPostDoc/projects/co-si/)
- [V–Oxo / Peroxo](https://skylark51.github.io/forPostDoc/projects/v-oxo-peroxo/)

사이트 파일은 `docs/`에 있습니다. `main`에 반영하면 GitHub Pages로 배포됩니다.

체크·메모는 현재 브라우저에 저장되며 각 대시보드의 백업 기능으로 옮길 수 있습니다. 계산 현황의 기준 시각은 각 화면에 표시됩니다. 로컬 원자료 링크는 웹에서 비활성화됩니다.

- [Ni(II) 진행 대시보드](https://skylark51.github.io/forPostDoc/projects/ni-dithiocarbazate/)
- [BODIPY · Se / Te](https://skylark51.github.io/forPostDoc/projects/bodipy/)

BODIPY 검토 스냅샷 재생성: `python tools/build-progress.py --audit <workbook_data.json>`
진행 상태는 표시된 확인 시각 기준이며, BODIPY의 개인 체크·메모는 서버 실행 상태와 별도로 브라우저에 저장합니다.
